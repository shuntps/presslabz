# Support

PressLabz is pre-alpha. **There are no supported releases**: nothing has shipped, so nothing carries maintenance or a compatibility promise yet.

What exists today:

- **Reproducible bugs** — open a [GitHub issue](https://github.com/shuntps/presslabz/issues) using the bug template. Issues are read and handled on a best-effort basis; there is no guaranteed response time.
- **Security vulnerabilities** — never in a public issue. Use [private vulnerability reporting](https://github.com/shuntps/presslabz/security), or email contact@presslabz.com if you cannot. See [`SECURITY.md`](SECURITY.md).
- **Questions and ideas** — a public issue is fine for those too, or contact@presslabz.com for anything that does not fit one.

There is no commercial support, no SLA and no support service of any kind at this stage. When releases begin, this page will say which versions are supported.
